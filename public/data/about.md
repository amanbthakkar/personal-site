# On Markets and Finance

Markets fascinate me. They're crowdsourced information in the best sense - but also places where people can be totally wrong and outliers can be right, like Burry in 2008. That tension is what makes them interesting.

During COVID, I dove deep into finance, markets, and cryptocurrencies. I watched [Andrew Lo's MIT lectures](https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/pages/video-lectures-and-slides/) on the basics of finance, completed a [Financial Engineering course](https://www.coursera.org/specializations/financialengineering) on derivatives and pricing, and participated in UC Berkeley's [first DeFi MOOC](https://defi-learning.org/f22). I even built a Bitcoin indicator that I still host on this site.

I haven't been writing about it much lately - the bear market hit, work got busy, and finding time to write is the hard part. But I'm still interested in betting and gambling, especially the math and psychology behind it. Prediction markets fascinate me too. I want to get better at understanding that math. Maybe someday.

If you want to talk about markets, mathematical models, or why I think certain cryptocurrencies are questionable investments, [let's chat](mailto:amanbthakkar@gmail.com).

# Why This Website

I built this website because I was tired of running the same [Python script](https://github.com/amanbthakkar/crypto_finance/blob/master/Power%20Oscillator.ipynb) every morning.

I had a Bitcoin indicator I'd built, and I was manually generating it each day. It worked, but it was tedious. So I automated it. Then I thought, "Well, if I'm hosting this anyway, why not buy a domain with my name and connect it?" And if I was doing that, it should be a personal website. I could show some other projects or blogs too.

The hard part, of course, is actually finding time to do the projects and write stuff. But here we are.

I decided to create a full-stack website and track visits myself (no Google Analytics - I wanted to own the data). That meant setting up a GitHub Pages frontend, an EC2 instance for the backend, buying a domain and pointing it to both GitHub and my backend server, enabling HTTPS on EC2, and so on. It's not much, but it's honest work.
